# tango

Italian words ending in `-go`.

## Examples

| Italian | Japanese |
|---|---|
| `prego` | どうぞ／どういたしまして |
| `lago` | 湖 |
| `ago` | 針 |
| `luogo` | 場所 |
| `albergo` | ホテル／宿 |
| `dialogo` | 対話 |
| `catalogo` | カタログ |
| `monologo` | 独白 |
| `prologo` | 序章 |

> `sango` is Japanese romanization (`珊瑚`), not Italian.
